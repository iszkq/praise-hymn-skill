# Chinese Hymn Skill

赞美诗歌与数字简谱技能，适用于：

- 歌谱图片登记、审计与批处理
- 数字简谱视觉转写和复核
- 中文会众赞美诗分析、编排与原创
- Suno 等音乐生成工具的敬拜歌曲创作准备

技能入口见 [SKILL.md](SKILL.md)。歌词创作规则见 [references/lyric-craft.md](references/lyric-craft.md)。

## 范围

本仓库只包含技能、脚本、参考文档和原创示例，不包含来源不明或版权状态未确认的原始歌谱图片。

## 校验

```text
python scripts/quick_validate.py .
```

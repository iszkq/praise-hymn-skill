# 审阅清单与签核规则

每首歌至少经过一次“转写复核”和一次“内容复核”；同一个人完成两次时要在记录中说明。批量项目可按风险抽样，但 P0/P1 或低置信度曲目必须逐首复核。

## 转写复核

- [ ] 文件路径、曲号、歌名和页序与来源一致。
- [ ] SHA-256 与登记 manifest 一致；没有把同号不同版本覆盖。
- [ ] 调号、拍号、速度、转调和结束提示已核对。
- [ ] 每小节拍值可解释；休止、延音、附点、时值线和三连音没有丢失。
- [ ] 八度点、连音弧、小节线、双终止线与原图位置一致。
- [ ] 每个歌词字/音节都与旋律事件对应；多节歌词顺序保持原样。
- [ ] 模糊区域进入 `uncertain_items`，而不是被静默修正。

## 音乐与会众复核

- [ ] 音域和跳进适合目标会众；高音或低音风险已标出。
- [ ] 句子重音与中文语义自然；换气点和延音不会切断词义。
- [ ] 主歌、副歌、桥段、尾句和重复次数有明确标签。
- [ ] 领唱、会众、二部和声与乐器建议没有被误写成原谱事实。
- [ ] 和声进入有明确音乐理由（终止、关键词、转段或共同回应），没有按每句句尾机械添加；主旋律始终清楚。
- [ ] 相邻句经过连唱测试：没有突然断开、旋律重置、停顿过长、重音跳变或伴奏断层。
- [ ] 句尾与下一句通过延音、级进、拾音、重复动机或和声连接；需要停顿时有明确呼吸或转段理由。

## 歌词可唱性复核（原创或改写）

- [ ] 已记录敬拜功能，以及歌词要带会众完成的中心动作/问题。
- [ ] 主歌句长服从旋律短语、中文重音和换气；3–8 字可作起点，但较长或较短的句子有音乐理由，并未为整齐而牺牲语义。
- [ ] 每个汉字有音符、延音或休止对应；轻字没有落在不自然的重音或最高音。
- [ ] 副歌有可在第一次听到后复唱的核心句；重复服务于记忆和回应，不是填充。
- [ ] 主歌、副歌、桥段各只承担清楚的动作；没有把讲章式解释塞进一行歌词。
- [ ] 已做朗读、拍值对齐和“领唱一次/会众一次”的跟唱测试。
- [ ] `lyric_issues` 中的 `too_long`、`stress_mismatch`、`breathless`、`vague`、`theology_dense` 已关闭或明确列为未决项。
- [ ] 语言有具体画面和真实自问；没有连续整齐金句、空泛抽象词或把十字架/宝血/悔改只当口号。

## 语言与神学复核

- [ ] 经文引用可追溯；不确定出处不写成确定引用。
- [ ] 上帝的作为、人的回应和祷告愿望分辨清楚。
- [ ] 医治、复兴、属灵争战等表述没有被夸大为无条件保证。
- [ ] 原创任务没有复制来源中的连续歌词、标题或可识别旋律。

## 签核

签核记录至少包括：审核人、角色、时间（ISO 8601）、通过/退回、问题编号、意见和下一步。存在未关闭的 P0/P1 或 `low` 置信度时，状态只能是 `review`、`rejected` 或 `needs-input`。
